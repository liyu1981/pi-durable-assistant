# Frontend design audit: shadcn/ui + Luma

Preset: `https://ui.shadcn.com/create?preset=b2D0wqNxT`, decoded with `pnpm dlx shadcn@latest preset decode b2D0wqNxT --json`:

| Field | Value |
| --- | --- |
| style | `luma` |
| baseColor | `neutral` |
| theme | `blue` |
| chartColor | `emerald` |
| font / fontHeading | `geist` / `inherit` |
| iconLibrary | `hugeicons` |
| radius | `default` |
| menuAccent / menuColor | `subtle` / `inverted-translucent` |

The earlier `minimal` design system was removed entirely: its tokens, fonts, CSS classes, and component markup are gone. `web/src/styles/tokens.css` now contains only the shadcn Luma theme (Tailwind v4 `@theme inline`, `:root` / `.dark` variables, `shadcn/tailwind.css`, `tw-animate-css`, Geist Variable).

## Components

- [x] Components come from `@/components/ui/*` generated by the shadcn CLI: Button, Card, Input, Label, Badge, Tabs, Dialog, Sheet, Separator, ScrollArea, Textarea, Tooltip, Switch, Select, Alert, Skeleton, Sonner.
- [x] Icons come from `@hugeicons/react` / `@hugeicons/core-free-icons`, matching the preset.
- [x] The app is wrapped with `TooltipProvider` and includes the Sonner `Toaster`.
- [x] Layout uses shadcn semantic tokens (`bg-background`, `text-foreground`, `text-muted-foreground`, `border-border`, `bg-card`, `bg-primary`, etc.); no raw hex colors in components.
- [x] Features preserved: conversation sidebar (active/archived, new/fork/archive/restore/remove), chat thread with tool badges and system notices, composer with attachments and steer/stop, status panel, task center, memory/skills, knowledge search, SSE reconnect. No WeChat.

## Accessibility and content

- [x] shadcn primitives provide focus states, keyboard interaction and ARIA roles; Dialog/Sheet provide focus trapping and Escape handling.
- [x] All UI text and comments are English. A CJK scan over `web/` (excluding `node_modules` and `dist`) returned zero matches.
- [x] Confirmation dialogs are used for destructive actions; status is conveyed with text, not color alone.
- [ ] **Manual follow-up:** interactive keyboard-only and visual pass in a real browser. No GUI browser is available here, so this is not signed off.

## Quality gate

- [x] `pnpm check` — Go tests/build, TypeScript, Biome (45 files), and Vite build pass (6482 modules, 727ms). The build emits a non-fatal >500 kB chunk-size warning.
- [x] The shadcn preset was decoded from the exact code supplied by the project owner, not guessed.
- [x] Embedded UI smoke test: `/` and the hashed JS asset are served with 200 by the Go binary on `0.0.0.0:3111`; a chat submission completed with `Demo task complete.` in the SSE view.

**Sign-off:** code-level shadcn/Luma compliance; interactive browser pass remains manual.
